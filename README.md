# Meu Portfólio - Fullstack Developer

Portfólio profissional desenvolvido com React, Material-UI e Framer Motion.

## 🚀 Tecnologias

- React 18
- Material-UI 5
- Framer Motion
- Vite
- React Markdown

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/teuuser/meu-portfolio.git

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
